# Física 2ª série · LDV

Listas interativas de Física da 2ª série do Colégio Leonardo da Vinci Alfa (Prof. Ricieri), com dica e resolução passo a passo. App instalável (PWA) publicado pelo GitHub Pages.

- `fonte/`: arquivos-fonte (`lista1.js` (Calorimetria), `lista2.js` (Gases ideais), `lista3.js` (1ª Lei)… e `engine_app.js` com `SITE` e `CONFIG`). Para montar o `index.html`: `python3 fonte/montar.py`.
- `registro/Codigo.gs`: script da planilha de registros (Google Apps Script).
- A cada publicação, aumentar `VERSAO` em `sw.js`.
